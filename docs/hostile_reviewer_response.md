# Hostile Reviewer Response

The strongest hostile review is correct: the original abstract controller was not a serious baseline. When the abstract policy is tuned on training trials, a constant squeeze value reaches 0.987 held-out success and outperforms the full-state controller at 0.962.

The paper should therefore not argue that the toy demonstrates abstraction-boundary failure. A future version would need a new environment where tuned abstract baselines fail specifically because they lack variables required for physical feasibility.
